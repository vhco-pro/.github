# Security policy

For a suspected vulnerability, open **Security → Advisories** in the affected
repository and choose **Report a vulnerability** if GitHub offers it. If the
option is unavailable, email [contact@vhco.pro](mailto:contact@vhco.pro) with
the public project name, a short summary, and the affected version if known.
Ask for a secure way to share sensitive follow-up.

Keep vulnerability details out of public issues and discussions. Use the
project's own security policy for its supported versions and disclosure process.
Follow its release documentation to verify artifacts.
