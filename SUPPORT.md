# Getting help

## Documentation

The user-facing documentation lives with the
[Frontend satellite](https://github.com/vhco-pro/stackweaver-frontend)
and is mirrored to the in-app docs viewer of any running Stackweaver
instance.

## Questions and discussion

- For **how-do-I** / **why-does-it-do-X** / design questions: open a
  GitHub Discussion on the satellite repo most relevant to your
  question.
- For **bug reports**: file an issue on the relevant satellite repo.
  The issue templates will route you.
- For **feature requests**: file an issue using the feature-request
  template on the relevant satellite repo, or open a Discussion first
  if the feature is large or ambiguous.

## Security

See [`SECURITY.md`](./SECURITY.md). Do not report vulnerabilities via
public issues.
